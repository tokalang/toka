---
title: 安装指南
description: 如何安装 Toka 编译器及构建工具。
---

Toka 为 macOS、Linux 和 Windows 发布预构建 release 包。macOS 与 Linux 安装脚本会下载当前 release，将编译器、项目管理器和标准库安装到 `~/.toka/`，并配置 shell 环境。

## 极速安装 (macOS & Linux)

运行安装脚本：

```bash
curl -fsSL https://tokalang.dev/install.sh | bash
```

脚本会识别系统和 CPU 架构，下载当前 release，并为常见 shell 配置 `PATH` 和 `TOKA_LIB`。

## Windows 安装

Windows release 包可以从 GitHub Releases 下载。当前 Windows 开发路径仍需要系统中存在 MSYS2 LLVM/Clang 环境，因为 `tokac.exe` 依赖 LLVM 工具链基础设施。

1. 前往 [GitHub Releases](https://github.com/tokalang/toka/releases) 页面。
2. 下载最新版本中带有 `Windows` 后缀的压缩包。
3. 将压缩包解压到一个您希望的目录（例如 `C:\tokalang`）。
4. 将解压目录下的 `bin` 文件夹添加至您的系统环境变量 `PATH` 中。
5. 将解压目录下的 `lib` 文件夹路径添加至名为 `TOKA_LIB` 的系统环境变量中。

> [!WARNING]
> 如果在没有 LLVM DLL 的干净 Windows 环境里运行 `toka build` 或 `toka run`，`tokac.exe` 可能会以 `0xC0000135` (`STATUS_DLL_NOT_FOUND`) 失败启动。

### 解决方案

安装与终端环境匹配的 MSYS2 工具链：

1. 下载并安装 [MSYS2](https://www.msys2.org)（默认安装到 `C:\msys64`）。
2. 运行对应命令：
   * **MSYS2 UCRT64 终端**（推荐）：
     ```bash
     pacman -S --noconfirm mingw-w64-ucrt-x86_64-clang mingw-w64-ucrt-x86_64-llvm mingw-w64-ucrt-x86_64-lld mingw-w64-ucrt-x86_64-polly make
     ```
   * **MSYS2 MinGW64 终端**：
     ```bash
     pacman -S --noconfirm mingw-w64-x86_64-clang mingw-w64-x86_64-llvm mingw-w64-x86_64-lld mingw-w64-x86_64-polly make
     ```
3. 将对应环境的二进制目录（如 UCRT64 对应的 `C:\msys64\ucrt64\bin` 或 MinGW64 对应的 `C:\msys64\mingw64\bin`）添加至您的 Windows 系统环境变量 `PATH` 中。


## 快速体验 (Hello World)

安装完成后，创建并运行一个小程序：

```bash
echo 'import std/io::{println}

fn main() {
    println("Hello, Toka World!")
}' > hello.tk

toka run hello.tk
```

## 从源码构建 (进阶)

如果你希望参与编译器开发，或测试尚未发布的改动，可以从源码构建。

### 前置依赖

- **LLVM 20 & LLD 20**: 需要安装匹配的开发头文件和库。
   - **Ubuntu/Debian**: 安装 `llvm-20-dev`、`liblld-20-dev`，如果你的 LLVM 包依赖 zstd，也需要 `libzstd-dev`。
   - **macOS**: 通过 Homebrew 安装：`brew install llvm@20 zstd`。
   - **Windows**: 通过 MSYS2 安装：
     * **UCRT64 终端**（推荐）：`pacman -S mingw-w64-ucrt-x86_64-llvm mingw-w64-ucrt-x86_64-lld`
     * **MinGW64 终端**：`pacman -S mingw-w64-x86_64-llvm mingw-w64-x86_64-lld`
- **CMake**: 3.15 或更高版本。
- C++17 编译器和平台构建工具，例如 Make、Ninja、GCC 或 Clang。

### 开始构建

1. 克隆代码仓库：
   ```bash
   git clone https://github.com/tokalang/toka.git
   cd toka
   ```

2. 配置并构建：
   ```bash
   cmake -S . -B build
   cmake --build build
   ```

3. 也可以选择运行全量重建脚本：
   ```bash
   ./rebuild.sh
   ```

编译完成后，`tokac` 和 `toka` 会出现在 `build/bin` 目录下。

## 环境配置

如果是源码构建，请将构建产物和标准库路径加入 shell 环境：

```bash
# 将刚刚编译出的 tokac 和 toka 所在的产物目录加入环境变量
export PATH="/path/to/tokalang/build/bin:$PATH"

# 关键设置：让编译器及包管理工具精准地定位到标准库
export TOKA_LIB="/path/to/tokalang/lib"

# 第三方库生态设置 (新增)：定义全局依赖搜索路径
# 多个路径可以使用冒号 ":" 分割。你可以将个人的常用库或下载的源码包放进这些目录，
# 然后在代码中就可以直接 `import mylib::{...}` 无缝导入！
export TOKA_PATH="/path/to/your/custom/libs:/another/lib/path"

# (可选) 指定用于底层链接的工具。默认为 macOS 原生或 /usr/local/opt/llvm@20/bin/clang
export TOKA_CLANG="/usr/local/opt/llvm@20/bin/clang"
```

> [!IMPORTANT]
> 请务必将 `/path/to/tokalang` 替换为您本地克隆该工程的实际完整绝对路径。

## 使用包管理工具开发

配置好环境变量后，可以用 `toka` 命令完成项目工作流。

### 1. 初始化新工程

创建一个新的可执行项目：

```bash
toka new my_app
cd my_app
```

该命令将为您生成：
- `src/main.tk`: 项目入口文件。
- `package.tk`: 包清单。
- `build.tk`: 构建编排脚本。

### 2. 引入文件与第三方依赖

Toka 支持直接的模块导入：

**导入本地文件（相对与绝对路径）**：
路径可以直接写在代码中，无需引号：

```toka
// 相对路径导入当前目录的 utils.tk
import ./utils::{foo, bar}
import ../lib/network::{get}

// 绝对路径导入
import /opt/shared/mylib::{baz}
```

**导入第三方包管理依赖**：
如果你通过 `toka add` 安装依赖，它会被记录到 `package.tk` 中，之后可以通过包别名导入：

```toka
import ansi::{...}
```

> **提示:** 编译器解析裸名称（如 `ansi`）时，会从标准库 (`TOKA_LIB`) 和全局搜索路径 (`TOKA_PATH`) 中查找。

### 3. 一键编译与运行

在项目目录中构建并运行当前可执行目标：

```bash
toka run
```

如果只想编译二进制而不运行，可以使用 `toka build`。
