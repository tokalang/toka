Toka publishes prebuilt release archives for macOS and Linux. The installer
downloads the latest stable release, installs the compiler, project manager,
and standard library under `~/.toka/`, and updates your shell environment.

## Quick Install (macOS & Linux)

Run the installer:

```bash
curl -fsSL https://tokalang.dev/install.sh | bash
```

The script detects your OS and CPU architecture, downloads the current release, and configures `PATH` and `TOKA_LIB` for common shells.

### Release Candidates

GitHub's `latest` endpoint intentionally selects a stable release. After
`v1.0.0-rc.2` is published, pass its exact tag:

```bash
curl -fsSL https://tokalang.dev/install.sh | bash -s -- v1.0.0-rc.2
```

## Windows Installation

Windows/MSYS2 is currently a dogfood and source-build path, not a blocking
release target and not a published SDK archive. Current Windows development
expects an MSYS2 LLVM/Clang environment on `PATH`, because `tokac.exe` uses the
LLVM toolchain infrastructure.

1. Clone the [Toka repository](https://github.com/tokalang/toka).
2. Install the matching MSYS2 toolchain below.
3. Configure and build with CMake from an MSYS2 UCRT64 or MinGW64 terminal.
4. Add `build/bin` to `PATH` and set `TOKA_LIB` to the repository's `lib` directory.

> [!WARNING]
> If you run `toka build` or `toka run` on a clean Windows machine without the required LLVM DLLs, `tokac.exe` may fail to start with `0xC0000135` (`STATUS_DLL_NOT_FOUND`).

### Resolution

Install the MSYS2 toolchain that matches your environment:

1. Download and install [MSYS2](https://www.msys2.org) (typically to `C:\msys64`).
2. Run the matching command:
   * **MSYS2 UCRT64 Terminal** (Recommended):
     ```bash
     pacman -S --noconfirm mingw-w64-ucrt-x86_64-clang mingw-w64-ucrt-x86_64-llvm mingw-w64-ucrt-x86_64-lld mingw-w64-ucrt-x86_64-polly make
     ```
   * **MSYS2 MinGW64 Terminal**:
     ```bash
     pacman -S --noconfirm mingw-w64-x86_64-clang mingw-w64-x86_64-llvm mingw-w64-x86_64-lld mingw-w64-x86_64-polly make
     ```
3. Add the corresponding binary directory (e.g., `C:\msys64\ucrt64\bin` for UCRT64 or `C:\msys64\mingw64\bin` for MinGW64) to your Windows system `PATH` environment variable.


## Quick Start (Hello World)

Once installed, create and run a small program:

```bash
echo 'import std/io::{println}

fn main() {
    println("Hello, Toka World!")
}' > hello.tk

toka run hello.tk
```

## Build From Source

If you want to contribute to the compiler or test unreleased changes, build from source.

### Prerequisites

- **LLVM 20 & LLD 20**: Install the matching development headers and libraries.
  - **Ubuntu/Debian**: Install `llvm-20-dev`, `liblld-20-dev`, and `libzstd-dev` if required by your LLVM package.
  - **macOS**: Install via Homebrew: `brew install llvm@20 zstd`.
  - **Windows**: Install via MSYS2:
    * **UCRT64 Terminal** (Recommended): `pacman -S mingw-w64-ucrt-x86_64-llvm mingw-w64-ucrt-x86_64-lld`
    * **MinGW64 Terminal**: `pacman -S mingw-w64-x86_64-llvm mingw-w64-x86_64-lld`
- **CMake**: Version 3.15 or higher.
- A C++17 compiler and platform build tool such as Make, Ninja, GCC, or Clang.

### Compiling

1. Clone the repository:
   ```bash
   git clone https://github.com/tokalang/toka.git
   cd toka
   ```

2. Configure and build:
   ```bash
   cmake -S . -B build
   cmake --build build
   ```

3. Optionally run the full rebuild helper:
   ```bash
   ./rebuild.sh
   ```

After compilation, `tokac` and `toka` are available in `build/bin`.

## Environment Configuration

For source builds, add the build output and standard library to your shell environment:

```bash
# Add the compiler and build tool to your PATH
export PATH="/path/to/tokalang/build/bin:$PATH"

# Essential: Tell the compiler and package manager where the standard library is
export TOKA_LIB="/path/to/tokalang/lib"

# Third-Party Libraries (New): Define global dependency search paths
# You can use ":" to split multiple paths. Drop your downloaded or personal
# library folders here, and you can seamlessly `import mylib::{...}` in your code!
export TOKA_PATH="/path/to/your/custom/libs:/another/lib/path"

# (Optional) Specify the Clang compiler for linking.
export TOKA_CLANG="/usr/local/opt/llvm@20/bin/clang"
```

> [!IMPORTANT]
> Make sure to replace `/path/to/tokalang` with the actual absolute path to your cloned repository.

## Package Manager Workflow

Once the environment variables are set up, use the `toka` command for project workflows.

### 1. Initialize a New Project

Create a new executable project:

```bash
toka new my_app
cd my_app
```

This generates:
- `src/main.tk`: The project entry file.
- `package.tk`: The package manifest.
- `build.tk`: The build orchestration script.

### 2. Importing Files & Dependencies

Toka supports direct module imports:

**Importing Local Files (Relative & Absolute)**:
Toka supports writing paths directly in code. No quotes are needed:

```toka
// Relative path import for utils.tk in current directory
import ./utils::{foo, bar}
import ../lib/network::{get}

// Absolute path import
import /opt/shared/mylib::{baz}
```

**Importing Package Manager Dependencies**:
If you installed a package with `toka add`, it is recorded in `package.tk` and can be imported by its package alias:

```toka
import ansi::{...}
```

> **Tip:** When resolving bare names like `ansi`, the compiler searches the standard library (`TOKA_LIB`) and configured global paths (`TOKA_PATH`).

### 3. Build and Run 

Inside a project directory, build and run the current executable:

```bash
toka run
```

Use `toka build` if you only want to compile the binary.
