# Getting Help

Use the channel that matches the outcome you need:

- **Question, design idea, or project showcase:** start a
  [GitHub Discussion](https://github.com/tokalang/toka/discussions/new/choose).
- **Reproducible compiler or SDK defect:** use the
  [bug report form](https://github.com/tokalang/toka/issues/new?template=bug_report.yml).
- **Installation, tooling, or workflow failure:** use the
  [developer-experience report form](https://github.com/tokalang/toka/issues/new?template=developer_experience.yml).
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md) and report it
  privately. Do not publish it in an issue or Discussion.

Before opening a report, include the exact Toka version, host platform, command
line, and the smallest source or manifest that reproduces the behavior.
