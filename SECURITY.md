# Security Policy

## Reporting a Vulnerability

Do not report suspected security vulnerabilities in public issues, Discussions,
or pull requests. Use GitHub's private reporting form for Toka instead:

<https://github.com/tokalang/toka/security/advisories/new>

Include the affected release or commit, host platform, a minimal reproduction,
and the security impact you observed. Avoid publishing an exploit or sensitive
details until maintainers have had an opportunity to triage the report.

## Coordinated Disclosure

Maintainers will handle accepted reports through GitHub's private advisory
workflow and coordinate disclosure with the reporter when a fix is ready.
