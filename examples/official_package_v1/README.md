# Official Package v1 Fixture

This is a zero-dependency library package that demonstrates the static
`package.tk` and `AI_CONTRACT` required by
[`docs/official_package_v1.md`](../../docs/official_package_v1.md).

It intentionally has no resolver-specific implementation beyond the existing
`package.tk` format. The fixture exists to keep the proposed official-package
convention compatible with today's package manager before `toka_regex` adopts
it.
