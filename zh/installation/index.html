Windows 安装

Section titled “Windows 安装”

Windows/MSYS2 当前是 dogfood 与源码构建路径，并非阻塞发布目标，也尚未发布 SDK archive。当前 Windows 开发要求 MSYS2 LLVM/Clang 环境已在 PATH 中， 因为 tokac.exe 依赖 LLVM 工具链基础设施。

  1. clone Toka 仓库。
  2. 安装下方对应的 MSYS2 工具链。
  3. 从 MSYS2 UCRT64 或 MinGW64 终端使用 CMake 配置并构建。
  4. 将 build/bin 加入 PATH，并将仓库的 lib 目录设为 TOKA_LIB。

[!WARNING] 如果在没有 LLVM DLL 的干净 Windows 环境里运行 toka build 或 toka run，tokac.exe 可能会以 0xC0000135 (STATUS_DLL_NOT_FOUND) 失败启动。

Section titled “从源码构建 (进阶)”

如果你希望参与编译器开发，或测试尚未发布的改动，可以从源码构建。

前置依赖

Section titled “前置依赖”
  • LLVM 20 & LLD 20: 需要安装匹配的开发头文件和库。
    • Ubuntu/Debian: 安装 llvm-20-dev、liblld-20-dev，如果你的 LLVM 包依赖 zstd，也需要 libzstd-dev。
    • macOS: 通过 Homebrew 安装：brew install llvm@20 zstd。
    • Windows: 通过 MSYS2 安装：
      • UCRT64 终端（推荐）：pacman -S mingw-w64-ucrt-x86_64-llvm mingw-w64-ucrt-x86_64-lld
      • MinGW64 终端：pacman -S mingw-w64-x86_64-llvm mingw-w64-x86_64-lld
  • CMake: 3.15 或更高版本。
  • C++17 编译器和平台构建工具，例如 Make、Ninja、GCC 或 Clang。
