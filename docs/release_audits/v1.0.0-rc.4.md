# v1.0.0-rc.4 qualification audit

**Status:** In qualification. This file records release evidence only after an
exact, committed RC4 revision completes the required four-platform gate. It is
not a tag, draft, or publication authorization and contains no candidate SHA
yet.

## Required record

Before an RC4 tag may be authorized, record:

- the immutable candidate SHA and unchanged compiler-interface compatibility
  key;
- one passing `toka.release-gate` v2 report for Linux x64, Linux arm64, macOS
  x64, and macOS arm64, each with `source_dirty=false` and
  `version_label=v1.0.0-rc.4`; the generated summary must verify that all four
  reports bind one candidate SHA and the fixed thirteen-stage set;
- one passing TaskHandle Lifecycle v2 conformance record per target, all bound
  to that SHA and the same v2 contract digest;
- the hosted run and artifact references; and
- SHA-256 digests plus clean installed first-hour replay results for all four
  final release archives, including `toka preview`.

The tag workflow may create only a **draft** after it has gathered and verified
all four native archives and `SHA256SUMS`. It cannot publish automatically.
After clean first-hour replay is recorded, protected promotion rechecks that
exact draft asset set before making it public. Historical RC2 and RC3 tags are
not inputs to this audit.
