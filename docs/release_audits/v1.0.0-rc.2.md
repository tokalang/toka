## Withdrawal

The candidate must not be published. Post-qualification review found a public
async-contract overclaim, absent JSON objects for rejected index/context/query
requests, a missing packaged preview helper, a zero exit status from failing
`toka test`, and a non-atomic release workflow. RC3 supersedes this candidate
on a new source revision and must repeat qualification from the beginning.
