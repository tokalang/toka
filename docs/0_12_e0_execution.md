# E0 执行边界

输入固定为 c4c1030cd33504a9f5d8dc670ab4ab0c1fc515e7；原始 0.11.0
发布 SDK 与本批候选分别绑定完整源码 SHA、归档摘要及四工具摘要。
本批是定向真实任务对照，继续 Preview，不启动 Q0。

执行者均为 Codex：AI_process 是保留失败及工作副本修订的脚本流程，
documentation_replay 是不做源码修订的文档代理重放。后者没有真人参与，
不能作为真人体验或独立参与者实验结论。源码修订在任务工作副本上进行，
固定输入不变；修订差异、原因、前后摘要和首次回执全部保留。

每项任务每种流程各一冷一热。冷条件是独立任务目录、空项目包缓存；热条件是
新建工作副本，复制前次任务缓存，Unicode 额外复用对应不可变发布锁。
这不是 B0 的五冷五热统计，也不代表操作系统页缓存被清空。
每步采用单调时钟；独立 900 秒保护上限触发时记为截断，不能当完成耗时。
registry add 的耗时包含获取和解析；当前 SDK 没有独立网络计时，因此该字段
明确为 null，不把整个 add 时间冒充网络耗时。

安装验收作业没有 checkout，仅下载完整 SDK、固定任务输入和带摘要的脚本。
打包作业可有 checkout，它的结果不充当源码不可见证明。本机诊断也不充当该证明。
SDK 安装目录不重复上传，完整归档由生产 artifact 保留，安装身份可据此重放。

交付包含真实应用二进制、源文件、锁、资源和本地依赖。路径依赖锁保留原宿主
绝对身份；迁移到另一宿主后重锁尚未验证，不声明源码交付可直接跨宿主运行。
作业成功只表示取证完成；功能完成率必须逐项读取 result.json，任何失败均保留。
