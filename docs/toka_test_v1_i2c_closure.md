## P01：显式选择已有的兼容发布包

B0 的不可变 `unicode:0.1.1` 锁触发 E0454/E0455，原 30 个功能失败继续
保留。旧发布包的 grapheme_slice 未声明对 text.buf 的返回依赖，错误值
传播也保留局部来源。源码中 Result::unwrap_err 的返回契约包含 self 来源，
不能把这一调用的局部来源检查关闭来获得通过。

Unicode `0.1.2` 已发布，其标签绑定
`f0910a57ebc121f037c4ba87f40fe6356af86b6c`。发布包声明最低编译器 0.10.0，
修订包括显式 `return <- text.buf` 与从错误字段重新构造脱离局部来源的值。
本批测试现有原始发布字节，不修改旧包、registry 或编译器。源码线索与
新旧实测共同支持消费者显式迁移；不据此宣称所有 E0455 拒绝都不存在误报。

迁移是新项目显式声明 `unicode="unicode:0.1.2"` 并生成新锁，不能隐式
升级旧 lock。固定 archive SHA 为
`b9aeb5db121875e094584597f7548e5ad992d794ecd7b513fc090ef368671e94`，
content SHA 为
`41ebf895976533b5d68f7bb57a46e3e736c4c94a99b828fbad64c68ba99559fc`。
冻结 SDK 8341ab9b 在真实 registry 路径完成 fetch、check、build、test、运行
及离线重放，锁节点、版本、摘要一致且每个项目锁前后不变；没有手工 -I。
旧 0.1.1 单列复现编译拒绝，不改写为成功。

## D27：保留输入策略，区分文件系统前提

原行要求在 POSIX 创建不可编码名称，macOS 的已测文件系统拒绝该创建，
此前只能标部分覆盖。本修订只条件化发现夹具前提：

- 显式原始字节 argv 的拒绝仍是所有 POSIX 的必测行为，退出 2，单一合法
  UTF-8 JSON，保留可还原 bytes；不得替换为另一个正常名称。
- 底层允许创建时，默认发现也必须执行并拒绝，同样验证 JSON 与原始 bytes。
- 底层拒绝创建时，保留 errno、输入 bytes、FS/宿主，以及同目录正常名称
  创建成功的对照；该发现变体写为 not_applicable_filesystem_precondition，
  不能写 passed。不得从一次 macOS 结果推广到所有卷或所有 macOS。
- 出现其他错误、正常名称也不能创建，或任何可运行发现失败，不能用此例外
  通过验收。原先的未运行记录保持未运行。

D27 行仍在 95 项范围内适用；它由显式拒绝加实际可运行的发现／已确认前提
拒绝组成，台账不通过删除整个 macOS 行来提高比例。候选全部适用断言通过
后才提交独立复审，复审前不将新契约或 I2-C 标为 Accepted。
